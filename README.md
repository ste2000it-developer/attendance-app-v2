# Attendance App V2

## หน้า Home — Dynamic Time-of-Day UI

หน้าแอปพนักงานออกแบบใหม่ตามตัวอย่างที่อนุมัติ เน้นมืออาชีพ น่าใช้ และอ่านง่ายสำหรับคนทุกวัย

- **05:00–10:59** ธีมเช้า
- **11:00–16:59** ธีมกลางวัน
- **17:00–19:59** ธีมเย็น
- **20:00–04:59** ธีมกลางคืน

อ้างอิงเวลาจริงในประเทศไทย (`Asia/Bangkok`) โดยไม่ขึ้นกับเขตเวลาของโทรศัพท์ ผู้ใช้สามารถกดไอคอนจานสีด้านบนเพื่อทดลองดูทั้ง 4 ธีม และสถานะเข้างาน–ออกงานได้ทันทีโดยไม่มีการบันทึกข้อมูล

## ข้อจำกัดในรุ่นนี้

- **ยังไม่เชื่อม Firebase / Authentication / Attendance records / ตารางงาน**
- เวลาเข้า–ออกในโหมดทดลองเป็นข้อมูลสาธิตเท่านั้น
- ปุ่มลงเวลาจะอธิบายว่าอยู่ระหว่างออกแบบ ไม่บันทึกข้อมูลเทียม
- ประวัติ การลา โปรไฟล์ และแอดมินยังไม่พัฒนา

ใช้เพื่อตรวจ UI/UX บนโทรศัพท์ก่อนพัฒนาระบบจริง
