# Attendance App V2

## หน้า Home — Dynamic Time-of-Day UI

หน้าแอปพนักงานออกแบบใหม่ตามตัวอย่างที่อนุมัติ เน้นมืออาชีพ น่าใช้ และอ่านง่ายสำหรับคนทุกวัย

- **05:00–10:59** ธีมเช้า
- **11:00–16:59** ธีมกลางวัน
- **17:00–19:59** ธีมเย็น
- **20:00–04:59** ธีมกลางคืน

อ้างอิงเวลาจริงในประเทศไทย (`Asia/Bangkok`) โดยไม่ขึ้นกับเขตเวลาของโทรศัพท์ ผู้ใช้สามารถกดไอคอนจานสีด้านบนเพื่อทดลองดูทั้ง 4 ธีม และสถานะเข้างาน–ออกงานได้ทันทีโดยไม่มีการบันทึกข้อมูล

## ภาพพื้นหลังที่สร้างด้วย Image Generation

ฉากเมืองริมทะเลสาบทั้ง 4 ช่วงเวลาเป็น **ภาพที่สร้างขึ้นจริง** ไม่ใช่ SVG ที่เขียนด้วยโค้ด โดยนำไฟล์ PNG ต้นฉบับมาปรับเป็น WebP ขนาด 960 × 720 พิกเซล เพื่อให้หน้า Home โหลดเร็วบนมือถือ:

- `public/backgrounds/morning.webp` — เช้า
- `public/backgrounds/day.webp` — กลางวัน
- `public/backgrounds/evening.webp` — เย็น
- `public/backgrounds/night.webp` — กลางคืน

คอมโพเนนต์ `src/SkyScene.tsx` ใช้ภาพ WebP จากโฟลเดอร์ดังกล่าว โดยยังคงเวลาและข้อความไว้เป็นองค์ประกอบ UI จริงตามเดิม

## ข้อจำกัดในรุ่นนี้

- **ยังไม่เชื่อม Firebase / Authentication / Attendance records / ตารางงาน**
- เวลาเข้า–ออกในโหมดทดลองเป็นข้อมูลสาธิตเท่านั้น
