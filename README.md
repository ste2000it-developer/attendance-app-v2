# Attendance App V2

## หน้า Home — Dynamic Time-of-Day UI

หน้าแอปพนักงานออกแบบใหม่ตามตัวอย่างที่อนุมัติ เน้นมืออาชีพ น่าใช้ และอ่านง่ายสำหรับคนทุกวัย

- **05:00–10:59** ธีมเช้า
- **11:00–16:59** ธีมกลางวัน
- **17:00–19:59** ธีมเย็น
- **20:00–04:59** ธีมกลางคืน

อ้างอิงเวลาจริงในประเทศไทย (`Asia/Bangkok`) โดยไม่ขึ้นกับเขตเวลาของโทรศัพท์ ผู้ใช้สามารถกดไอคอนจานสีด้านบนเพื่อทดลองดูทั้ง 4 ธีม และสถานะเข้างาน–ออกงานได้ทันทีโดยไม่มีการบันทึกข้อมูล

## ภาพพื้นหลังที่สร้างด้วย Image Generation

ฉากเมืองริมทะเลสาบทั้ง 4 ช่วงเวลาเป็น **ภาพที่สร้างขึ้นจริง** ไม่ใช่ SVG ที่เขียนด้วยโค้ด โดยนำไฟล์ PNG ต้นฉบับมาปรับเป็น WebP ขนาด 960 × 720 พิกเซล เพื่อให้หน้า Home โหลดเร็วบนมือถือ:

- `public/backgrounds/morning.webp` — เช้า
- `public/backgrounds/day.webp` — กลางวัน
- `public/backgrounds/evening.webp` — เย็น
- `public/backgrounds/night.webp` — กลางคืน

คอมโพเนนต์ `src/SkyScene.tsx` ใช้ภาพ WebP จากโฟลเดอร์ดังกล่าว โดยยังคงเวลาและข้อความไว้เป็นองค์ประกอบ UI จริงตามเดิม

## เชื่อมข้อมูลพนักงานและตารางงาน (V2)

แอปอ่านข้อมูลจาก Firebase Firestore โดยผูกเอกสารกับ UID ของบัญชี Google ที่เข้าสู่ระบบ:

- `employees/{uid}`: โปรไฟล์พนักงาน (รหัสพนักงานไม่ใช่ UID)
- `employees/{uid}/workDays/{YYYY-MM-DD}`: ตารางงานรายวันในเขตเวลาไทย
- ข้อมูล Firestore เป็นของจริง ไม่ใช่ข้อมูลตัวอย่างในหน้า Preview
- **ยังไม่มีหน้าสร้างพนักงานสำหรับ HR**: ผู้ดูแลต้องเพิ่มเอกสารผ่าน Firebase Console หรือระบบจัดการที่ปลอดภัยก่อน จึงจะเห็นข้อมูลในแอป

ตัวอย่างข้อมูลพนักงานสำหรับกำหนดรูปแบบเอกสาร (ห้ามใช้แทนข้อมูลจริง):

```json
{
  "code": "EMP001",
  "firstName": "ชื่อจริง",
  "lastName": "นามสกุล",
  "nickname": "ชื่อเล่น",
  "department": "สำนักงาน",
  "position": "พนักงาน",
  "startDate": "2026-11-01",
  "workPattern": "office",
  "scheduleType": "morning",
  "status": "active"
}
```

- `workPattern`: `office` = จ.–ศ. 08:00–17:00; `field` = จ.–ส. ตามงาน (อาทิตย์หยุด เว้นแต่มีตารางรายวัน)
- `scheduleType`: `morning`, `afternoon`, `night`, `byJob` เป็นประเภทตารางงานสำหรับแสดงผล ไม่ใช่เวลาที่สมมติขึ้น
- `status`: `active` หรือ `inactive`. ถ้าหายไป จะถือว่าไม่เปิดใช้งานเพื่อความปลอดภัย
- วันหยุดพิเศษจาก Google Calendar ยังไม่เชื่อม จึงยังไม่หักวันหยุดพิเศษจากตารางออฟฟิศอัตโนมัติ

ตัวอย่างเอกสารตารางงานรายวัน:

```json
{
  "kind": "work",
  "startTime": "09:00",
  "endTime": "18:00",
  "title": "งานติดตั้ง",
  "siteName": "ไซต์งาน A",
  "note": ""
}
```

- `kind` เป็น `work`, `off`, `holiday`; เวลาเป็น `HH:mm` ตามเวลาไทย
- ตารางรายวันมีลำดับความสำคัญเหนือเวลาออฟฟิศปกติ และรองรับเวลาออกข้ามวัน
- **`firestore.rules` เป็นกฎตัวอย่างที่ยังไม่ได้ Deploy**: GitHub Pages ไม่ได้อัปเดตกฎ Firestore ต้องตรวจและผสานกฎกับของเดิมก่อนใช้งาน อย่าแทนที่กฎของระบบอื่นโดยไม่ตรวจสอบ
- การเขียนข้อมูลพนักงานให้เป็นหน้าที่ผู้ดูแลเท่านั้น พนักงานอ่านได้เฉพาะข้อมูลของตัวเอง

## ข้อจำกัดในรุ่นนี้

- Google Login เชื่อม Firebase Authentication แล้ว; โปรไฟล์/ตารางงานเริ่มอ่าน Firestore ได้เมื่อมีข้อมูลและกฎอนุญาต
- **ยังไม่เชื่อมระบบลงเวลา GPS, OT, Push Notification, การอนุมัติใบลา และรายงานจริง**
- เวลาเข้า–ออกและรายการลาในโหมดทดลองไม่ใช่ข้อมูลจริง
- ระบบจัดการพนักงานและสถานที่ทำงานสำหรับ HR ยังไม่เชื่อมข้อมูลจริง

อย่านำไปใช้ตอกบัตรพนักงานจริงจนกว่าระบบสิทธิ์และการลงเวลาจะพร้อม
