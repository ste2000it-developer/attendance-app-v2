### เปิดหน้าทดลอง
- ฝั่งพนักงาน: `/attendance-app-v2/`
- ฝั่ง HR ตัวอย่าง: `/attendance-app-v2/?hr-preview=1`
- หน้า HR เป็นข้อมูลในหน่วยความจำเท่านั้น หายเมื่อโหลดหน้าใหม่ **ห้ามนำข้อมูลจริงมาบันทึกผ่านหน้าทดลอง**

## ยังไม่ใช่ระบบใช้งานจริง
- ยังไม่มีบริการ/ฐานข้อมูลที่เก็บข้อมูลพนักงาน ตารางงาน เวลาเข้า–ออก การลา พิกัด และ audit อย่างถาวร
- ยังไม่ได้เชื่อม Google Calendar “ปฏิทินบริษัท” เพื่อแยกวันหยุดกับกิจกรรม
- ยังไม่มี Push Notification ที่ส่งได้แม้ปิดแอป (ต้องมี service worker, permission และ server scheduling)
- ยังไม่มีการกำหนดสิทธิ์ HR/พนักงานจริงและการอนุมัติข้อมูลจริง
- รายงานเข้า/ขาด/ลา/สายรายปี–เดือน–วันจริงต้องอาศัยข้อมูลที่เชื่อถือได้ ไม่ควรเดาจากช่องว่างในตัวอย่าง
- ยังไม่มี API บันทึกการตอกบัตรจริงให้ตรวจ GPS และสิทธิ์ผู้ใช้ฝั่งเซิร์ฟเวอร์
- **ไม่เชื่อมหรือ Deploy Firebase/Firestore เพิ่มเติม เนื่องจากผู้ใช้สั่งห้ามก่อนหน้านี้** และไม่แตะ V1
